# Industrial Water Quality Monitoring and Pollution-Risk Prediction Using Python

## Project Overview

This project aims to analyze water quality data and identify patterns associated with potentially problematic water-quality conditions.

The project uses Python for data analysis, visualization, and basic machine learning.

## Technologies and Tools

- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Git
- GitHub

## Machine Learning Algorithms

- K-Nearest Neighbors (KNN)
- Logistic Regression
